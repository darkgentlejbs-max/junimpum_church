# 주님품교회 홈페이지
대한예수교장로회(통합) 주님품교회 공식 홈페이지입니다.

## 기술 스택
- **프레임워크:** Next.js 14+ (App Router)
- **언어:** TypeScript
- **스타일링:** Tailwind CSS, Framer Motion
- **아이콘:** Lucide React

## 프로젝트 실행 방법

1. 의존성 설치
```bash
npm install
```

2. 개발 서버 실행
```bash
npm run dev
```

3. 브라우저에서 `http://localhost:3000` 으로 접속하여 확인합니다.

## 배포
- 본 프로젝트는 Vercel, Netlify 등 Next.js를 지원하는 플랫폼에 손쉽게 배포할 수 있도록 구성되어 있습니다.
